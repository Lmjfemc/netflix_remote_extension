Netflix LAN Remote

같은 Wi-Fi의 휴대폰으로 Netflix를 제어하세요.

상태 확인 중…

연결 코드

페어링된 휴대폰은 서버를 다시 켜도 코드 없이 연결됩니다. 새 코드를 발급하고 연결된 휴대폰을 끊으려면 연결 초기화를 누르세요.

최초 설치 안내

배포 ZIP을 풀고 install.cmd를 실행하세요. 확장 ID는 자동으로 설정됩니다.

설치 경로: %LOCALAPPDATA%\NetflixRemote\extension

서버가 켜져 있을 때만 연결됩니다. Chrome을 종료하면 서버도 종료됩니다. 연결이 예기치 않게 끊기면 끄기를 누르기 전까지 자동으로 다시 시작합니다.
